# 🍌 SangSmart — Smart Agriculture Application

### Making Banana Farming Smarter.

SangSmart is a smart agriculture mobile application designed to support banana farmers through digital agricultural education, farmland monitoring, and AI-powered consultation.

The name **SangSmart** comes from two words:
- **Sang**: Banana.
- **Smart**: Intelligent.

The application aims to help banana farmers access agricultural knowledge and manage their farming activities through digital technology.

## ✨ Main Features

### 📚 1. Agricultural Education

Provides agricultural learning resources for banana farmers through:
- Educational articles.
- Agricultural videos.
- Banana cultivation guides.
- Plant care information.

### 🌱 2. Land Monitoring

A digital monitoring interface designed to help farmers understand their farmland conditions.

- Land condition monitoring.
- Soil moisture information.
- Plant condition monitoring.
- Monitoring dashboard.

### 👨‍🌾 3. Expert Consultation

A consultation feature that connects banana farmers with agricultural experts to help them understand and address challenges in banana cultivation.

- Consultation with agricultural experts.
- Agricultural problem discussions.
- Expert guidance for banana cultivation.
- Assistance in addressing plant-related issues.

### 🤖 4. AI Chatbot Assistant

An AI-powered chatbot designed to provide interactive assistance and answer banana farmers' questions about agriculture.

- Interactive AI chatbot.
- Agricultural question and answer.
- Banana cultivation information.
- Instant farming assistance.
